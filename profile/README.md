# RackMarshal™

**Local-first infrastructure operations and incident management for self-hosted systems.**

RackMarshal develops tools for observing self-hosted infrastructure, maintaining durable operational state, detecting and tracking incidents, and verifying recovery.

The project currently focuses on Linux and Proxmox-based environments, with broader self-hosted and small-infrastructure support planned.
